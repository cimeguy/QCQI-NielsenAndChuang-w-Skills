## 内容

- **`.nb` 笔记**：第 1、2、4、5、6 章 + 第八章补充（Mathematica 笔记）。
- **PDF 笔记**：第 8、9、10、11 章（Goodnotes 手写）。
- **`skill_set/`**：把上述 `.nb` 笔记转换成的一组 **Agent Skills**（可被 Claude Code / GitHub Copilot CLI / Amp 加载），用于学习、复习与查询。详见 [`skill_set/README.md`](skill_set/README.md)。

| Skill | 章节 |
|---|---|
| `qcqi-ch01-intro` | 第一章 量子计算简介 |
| `qcqi-ch02-linalg-qm` | 第二章 线性代数与量子力学 |
| `qcqi-ch04-circuits` | 第四章 量子线路与量子模拟 |
| `qcqi-ch05-qft` | 第五章 QFT 与 Shor 算法 |
| `qcqi-ch06-search` | 第六章 量子搜索 (Grover) |
| `qcqi-ch08-quantum-channels` | 第八章补充 量子信道 |
| `qcqi-key-points` | 各章关键知识点汇总（复习/导航） |
