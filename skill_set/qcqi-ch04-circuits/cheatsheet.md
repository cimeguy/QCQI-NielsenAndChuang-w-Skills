# 速查表 · QCQI 第四章

## 单比特门速查
| 门 | 矩阵 | 作用 |
|---|---|---|
| Rx(θ) | cos(θ/2)I−i sin(θ/2)X | 绕 x 轴转 θ |
| Ry(θ) | cos(θ/2)I−i sin(θ/2)Y | 绕 y 轴转 θ；可生成所有单比特门 |
| Rz(θ) | diag(e^{−iθ/2},e^{iθ/2}) | 绕 z 轴转 θ |
| H | (1/√2)[[1,1],[1,−1]] | 等权叠加，交换 X↔Z |
| S | diag(1,i) | π/2 相位 |
| T | diag(1,e^{iπ/4}) | π/4 相位 (π/8 门) |

## 多比特门速查
| 门 | 作用 | 备注 |
|---|---|---|
| CNOT | 控制=1 翻转目标 | 纠缠生成器 |
| CZ | 控制=1 施 Z | 对称；= 目标侧 H·CNOT·H |
| SWAP | 交换两比特 | = 3×CNOT |
| Toffoli | 双控制翻转 | 经典可逆通用门 |

## 通用性三步（决策）
1. 任意 U(2ⁿ) → **二级幺正门**之积。
2. 二级门 → **单比特门 + CNOT**。
3. 单比特门 → **{H, T}** 稠密逼近 ⇒ 通用集 **{H, T, CNOT}**。
- 逼近精度 ε：门数 O(log^c(1/ε))（Solovay-Kitaev）。

## 测量原理速记
- **延迟测量**：中途测+经典控制 ⟺ 量子受控门+末端测。
- **隐含测量**：末端未读比特 = 已测。
- **U²=I 的测量**：辅助比特 H–受控U–H–测，取 ±1 投影。

## 量子模拟决策
| 想要 | 怎么做 |
|---|---|
| 模拟 e^{−iHt}, H=ΣAᵢ | 切片 + Trotter |
| 误差 O(Δt²) | 1 阶 ∏e^{−iAᵢΔt} |
| 误差 O(Δt³) | 2 阶对称 Suzuki-Trotter |
| 估计误差 | 迹距离 / ‖U−Trotter‖ vs 门数 |
| 误差根源 | BCH：[A,B]≠0 |

**初始化 → 幺正变换 → 测量**（DiVincenzo 五要素的核心）。
