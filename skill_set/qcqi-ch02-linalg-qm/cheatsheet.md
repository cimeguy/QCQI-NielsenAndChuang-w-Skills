# 速查表 · QCQI 第二章

## 算符分类速查
| 算符 | 定义 | 角色 |
|---|---|---|
| 正规 | AA†=A†A | 可幺正对角化（谱定理） |
| Hermite | A†=A | 可观测量，本征值实 |
| 幺正 | U†U=I | 演化/门，保内积 |
| 投影 | P²=P, P†=P | 命题 / PVM 元 |
| 正定 | A≥0 | 密度矩阵、POVM 元 |

## 纯态 vs 混态判据（四者等价）
| 判据 | 纯态 | 混态 |
|---|---|---|
| Tr(ρ²) | =1 | <1 |
| 秩 | 1 | >1 |
| 凸分解 | 不可 | 可 |
| Bloch \|r\| | =1（面） | <1（内），心=I/2 |

## 测量速查
- **概率**：P(i)=Tr(ρPᵢ)，纯态 =⟨ψ|Pᵢ|ψ⟩。
- **测后态**：PᵢρPᵢ/P(i)（PVM）。
- **期望**：⟨A⟩=Tr(ρA)；**方差** (ΔA)²=⟨A²⟩−⟨A⟩²。
- **PVM**：正交+幂等+ΣP=I（要测后态用它）。
- **POVM**：只需 E≥0 且 ΣE=I（只求概率/最优区分用它）。

## 复合系统工具决策
- 要**子系统状态** → 偏迹 ρ_A=Tr_B(ρ_AB)。
- 要**判断/量化两体纠缠** → 施密特分解，看施密特数。
- 要**把混态变纯态** → 纯化（加辅助系统）。
- 要**判定全局纯态是否纠缠** → 施密特数 >1 ⟺ 纠缠。

## 分解方法速记
| 分解 | 形式 | 用途 |
|---|---|---|
| 谱分解 | A=Σaᵢ\|i⟩⟨i\| | 正规算符对角化 |
| SVD | A=UDV† | 秩、自由度、低秩逼近 |
| 极分解 | A=UP | 模-相位类比 |
| 施密特 | \|Ψ⟩=Σλᵢ\|iₐ⟩\|i_b⟩ | 两体纠缠 |

## 核心红线
1. **正交才能完美区分**；非正交只能 POVM 无错-弃权区分。
2. **不可克隆**：任意未知态不可复制。
3. **Bell 违反**：纠缠否定局域实在论。
4. **偏迹惯例**：全程统一一种指标约定。
