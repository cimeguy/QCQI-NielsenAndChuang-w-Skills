# Grover 构件与技巧 · QCQI 第六章

## 把布尔预言机变成相位翻转预言机
**何时用**：手头是 Uf（布尔型），但 Grover 需要相位翻转 O。
**怎么做**：辅助比特置 |−⟩，作用 Uf，相位回踢得 |x⟩→(−1)^{f(x)}|x⟩；辅助比特解耦。
**权衡**：多一个辅助比特；辅助初态 |0⟩/|1⟩ 不影响成功概率。

## 用可逆逻辑搭布尔预言机
**何时用**：把一个经典判定函数（如 3-SAT）做成 Uf。
**怎么做**：写真值表 → 用 Toffoli/CNOT 等可逆门搭线路 → 辅助比特记 f(x)，用完反计算清理。
**权衡**：需要 ancilla 与 uncompute；门数随 clause 数增长。

## 把 Grover 迭代看作 2 维旋转
**何时用**：分析成功概率、决定迭代次数。
**怎么做**：在 |α⟩-|β⟩ 平面里，G 是转角 θ 的旋转，sin(θ/2)=√(M/N)。
**权衡**：仅 2 维有效；多解时 |β⟩ 是所有解的叠加（测得随机一个解）。

## 卡准最优迭代次数
**何时用**：实际运行 Grover。
**怎么做**：R=round((π/4)√(N/M))；M 未知时可用指数递增猜测策略或量子计数先估 M。
**权衡**：次数偏离最优会过冲，成功概率振荡下降。

## 用量子模拟"设计"算法（启发式）
**何时用**：想理解 G 的来历 / 设计变体。
**怎么做**：取 H=|ψ⟩⟨ψ|+|x⟩⟨x|，Trotter 化 e^{−iHt}，令 t=π 使两因子各成反射 ⇒ G=−HO。
**权衡**：是推导视角，非更优实现。

## 反模式
- **迭代次数照搬 √N 不取整/不按 M 调整**：会过冲。
- **忘记 M>1**：最优次数含 √(N/M)，且只能得到随机一个解。
- **直接用布尔预言机不转相位**：Grover 的反射需要相位翻转 O。
- **测量过早或过晚**：必须在态最接近 |β⟩ 时测。
