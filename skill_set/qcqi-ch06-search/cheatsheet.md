# 速查表 · QCQI 第六章

## 算法流程
1. **初始化**：H^{⊗n}|0⟩ = 均匀叠加 |ψ⟩；（辅助比特 |−⟩）。
2. **重复 G** 约 (π/4)√(N/M) 次。
3. **测量** index register → 高概率得解。

## Grover 迭代 G = −H·O
| 部件 | 作用 | 几何 |
|---|---|---|
| O（预言机） | O|x⟩=(−1)^{f(x)}|x⟩ | 关于 |α⟩ 反射 |
| H（2|ψ⟩⟨ψ|−I） | 对均值翻转 | 关于 |ψ⟩ 反射 |
| G=−HO | 一次迭代 | 转角 θ 的旋转 |

## 关键数字
- **旋转角**：sin(θ/2)=√(M/N)，M≪N 时 θ≈2√(M/N)。
- **最优迭代次数**：R ≈ (π/4)√(N/M)；M=1 → (π/4)√N。
- **复杂度**：O(√N) 查询（经典 O(N)）——平方加速。
- N=64,M=1 → R≈6。

## 预言机两型
| 类型 | 形式 | 备注 |
|---|---|---|
| 布尔 | Uf|x⟩|q⟩=|x⟩|q⊕f(x)⟩ | 用辅助比特记 f |
| 相位翻转 | O|x⟩=(−1)^{f(x)}|x⟩ | 辅助 |−⟩+回踢从布尔得到 |

## 几何要点
- 平面：|α⟩（非解）、|β⟩（解）。
- 初态 |ψ⟩=√((N−M)/N)|α⟩+√(M/N)|β⟩。
- 反射 = Householder；两次反射 = 一次旋转。

## 注意事项
- 成功概率随迭代次数**振荡**，必须卡准次数（过冲会下降）。
- 多解 M>1：得到随机一个解；M 未知先做量子计数或指数猜测。
- 布尔（辅助 |0⟩/|1⟩）与相位翻转实现成功概率相同。

## 启发式来源
H=|ψ⟩⟨ψ|+|x⟩⟨x| → Trotter，t=π → 两反射复合 = G=−HO。
