# 术语表 · QCQI 第六章

**Grover 迭代 G** — G=−HO，预言机 + 关于 |ψ⟩ 的反射 (6.2,6.3)
**Householder 变换** — 关于某态的反射 2|ψ⟩⟨ψ|−I (6.3)
**index register** — 存放 |x⟩ 的 n 个 qubit (6.1)
**inversion about the mean** — 对均值翻转，= 关于 |ψ⟩ 反射 (6.2)
**|α⟩（非解空间）** — 所有非解的均匀叠加 (6.3)
**|β⟩（解空间）** — 所有解的均匀叠加 (6.3)
**3-SAT** — 构造布尔预言机的示例布尔函数 (6.1)
**布尔预言机** — Uf|x⟩|q⟩=|x⟩|q⊕f(x)⟩ (6.1)
**成功概率** — 随迭代次数振荡的测得解概率 (6.4)
**均匀叠加初态 |ψ⟩** — H^{⊗n}|0⟩=(1/√N)Σ|x⟩ (6.2)
**平方加速** — O(√N) vs 经典 O(N) (6.2,6.4)
**最优迭代次数** — ≈(π/4)√(N/M) (6.4)
**相位回踢** — 辅助比特 |−⟩ 把布尔预言机变相位翻转 (6.1)
**相位翻转预言机 O** — O|x⟩=(−1)^{f(x)}|x⟩ (6.1)
**旋转角 θ** — sin(θ/2)=√(M/N)，每次迭代转过 θ (6.3)
**搜索问题** — N 对象中找 M 个 f=1 的解 (6.1)
**启发式推导** — 猜 H=|ψ⟩⟨ψ|+|x⟩⟨x|，Trotter 导出 G (6.5)
**过冲 (overshoot)** — 迭代过多致成功概率下降 (6.4)
