# 1.2 量子比特

## 核心思想
量子比特 (qubit) 是量子信息的基本单元：可处于 |0⟩ 与 |1⟩ 的线性叠加；测量塌缩为基态、概率为幅的模方；纯态可用 Bloch 球面上的点几何表示。

## 关键概念
- **qubit**：|ψ⟩ = α|0⟩ + β|1⟩，α,β∈ℂ，|α|²+|β|²=1。计算基 {|0⟩,|1⟩} 是常用 ONB（标准正交基）。
- **态矢量与密度矩阵**：密度矩阵 ρ = |ψ⟩⟨ψ|，Tr(ρ)=|α|²+|β|² = 1（迹为 1 即各测量结果概率归一）。
- **物理状态与物理量**：经典——状态是确定值；量子——状态是叠加，物理量由算符（如 Pauli σx,σy,σz）刻画，测量得本征值且概率性塌缩。

## 心智模型
- **Bloch 矢量**：纯态参数化 |ψ⟩ = cos(θ/2)|0⟩ + e^{iφ}sin(θ/2)|1⟩，对应单位球面点 r = (sinθcosφ, sinθsinφ, cosθ)。θ 为纬度角、φ 为经度角。可用 rᵢ = Tr(ρ σᵢ) 计算 Bloch 分量。
- **态的制备 = 旋转**：任意 qubit 态 |ψ⟩ 都能找到 U∈U(2) 使 |ψ⟩ = U|0⟩——几何上是绕躺在 x-y 平面的某根轴旋转某角度。（思考：实现同一目标的转轴/转角不唯一。）

## 测量
- **计算基测量**：测 |ψ⟩=α|0⟩+β|1⟩，得 |0⟩ 概率 |α|²，得 |1⟩ 概率 |β|²。
- **非计算基测量**：可测 σx 等其它可观测量，等价于先旋转到该基再做计算基测量。

## 多比特与 Bell 基
- **多比特计算基**：n 比特张成 2ⁿ 维空间，基矢 |00…0⟩…|11…1⟩。
- **Bell 基（最大纠缠）**：|Φ±⟩=(|00⟩±|11⟩)/√2，|Ψ±⟩=(|01⟩±|10⟩)/√2。
- **Bell 关联**：在计算基下测量 Bell 态（如 |Φ+⟩），两比特总是得到**相同**结果——纠缠的标志。

## 关键要点
1. qubit 的"信息"藏在概率幅里，测量只给出概率性的一比特结果。
2. 单 qubit 纯态 ↔ Bloch 球面点；混合态 ↔ 球内点（|r|<1）。
3. Bell 态体现纠缠：局部测量结果强关联，无法写成张量积。

- **1.6**：测量概率性是量子信息论的出发点。
