# 术语表 · QCQI 第一章

**BQP** — Bounded-error Quantum Polynomial time，量子多项式时间复杂性类；因数分解 ∈ BQP (1.4)
**BPP** — Bounded-error Probabilistic Polynomial time，经典概率多项式时间类；核心问题 BPP ⊊ BQP? (1.4)
**Bell 基 / Bell 态** — 四个最大纠缠两比特态 |Φ±⟩,|Ψ±⟩；局部测量结果强关联 (1.2)
**Bloch 矢量 / Bloch 球** — 单 qubit 纯态 ↔ 单位球面点 (sinθcosφ, sinθsinφ, cosθ) (1.2)
**CNOT** — 受控非门，控制位为 1 时翻转目标位；纠缠生成器 (1.3)
**Deutsch 算法** — 一次 Uf 判断 f 常数/平衡，经典需两次 (1.4)
**Deutsch-Jozsa 算法** — Deutsch 推广到 n 位函数 (1.4)
**Hadamard 门 (H)** — 制备等权叠加，H|0⟩=(|0⟩+|1⟩)/√2 (1.3)
**Landauer 原理** — 擦除信息有最小能耗 kT ln2，可逆计算可规避 (1.4)
**LOCC** — 本地操作 + 经典通信 (Local Operations and Classical Communication) (1.3)
**NISQ** — 含噪中等规模量子 (Noisy Intermediate-Scale Quantum) (1.5)
**ONB** — 标准正交基 (Orthonormal Basis)，如计算基 {|0⟩,|1⟩} (1.2)
**Pauli 矩阵 (σx,σy,σz)** — 单比特可观测量/门的基本算符 (1.2,1.3)
**Rn(θ) / Rx,Ry,Rz** — 绕轴 n 旋转 θ 的单比特门 (1.3)
**SWAP 门** — 交换两比特，= 三个 CNOT 级联 (1.3)
**Shor 算法** — 多项式时间因数分解，基于量子 Fourier 变换 (1.1,1.4)
**Grover 算法** — 非结构化搜索 O(N)→O(√N) (1.1,1.4)
**Stern-Gerlach** — 自旋测量原型实验，验证测量不对易性 (1.5)
**T 门 (π/8 门)** — diag(1, e^{iπ/4}) 相位门 (1.3)
**Toffoli 门 (CCNOT)** — 双控制非门，经典可逆计算通用门 (1.3,1.4)
**Turing-Church 论题** — 能行可计算 = 图灵可计算；无反例，多模型等价 (1.1)
**U(2) / SU(2)** — 单比特幺正群；(SU(2)⋉U(1))/2 = U(2) (1.3)
**Uf (oracle)** — |x⟩|y⟩→|x⟩|y⊕f(x)⟩，封装函数 f 的量子黑盒 (1.4)
**z-y-z 分解** — 任意单比特门 = e^{iα}Rz(β)Ry(γ)Rz(δ)，旋量欧拉角 (1.3)
**叠加 (superposition)** — |ψ⟩=α|0⟩+β|1⟩，量子态的线性组合 (1.2)
**不可克隆定理** — 未知量子态不可被完美复制；禁止线路扇出 (1.3)
**密度矩阵 ρ** — ρ=|ψ⟩⟨ψ|，Tr(ρ)=1；描述纯/混合态 (1.2)
**退相干 (decoherence)** — 量子态因环境耦合失去相干性 (1.1,1.5)
**纠缠 (entanglement)** — 不可写成张量积的关联态；量子独有资源 (1.2,1.6)
**量子并行** — 一个幺正变换中同时计算 f 在多个 x 的值 (1.4)
**量子隐形传态** — 纠缠+经典通信传未知态，不传物质 (1.3)
**量子层析 (tomography)** — 测量重构未知态/过程 (1.5)
**通用门集合** — 能以任意精度模拟任何幺正变换的门集，如 {H,T,CNOT} (1.3)
**阈值定理** — 噪声低于阈值即可实现任意规模容错量子计算 (1.5)
**von Neumann 熵** — 量子版 Shannon 熵，量子信息论核心量 (1.6)
