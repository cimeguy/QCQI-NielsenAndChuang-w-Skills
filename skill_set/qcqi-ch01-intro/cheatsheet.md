# 速查表 · QCQI 第一章

## 常用单比特门
| 门 | 矩阵 (计算基) | 作用 |
|---|---|---|
| X (NOT) | [[0,1],[1,0]] | 翻转，绕 x 轴 π |
| Y | [[0,−i],[i,0]] | 绕 y 轴 π |
| Z | [[1,0],[0,−1]] | 相位翻转 |β⟩→−|β⟩ |
| H | (1/√2)[[1,1],[1,−1]] | 等权叠加；交换 X↔Z |
| S | [[1,0],[0,i]] | π/2 相位 |
| T | [[1,0],[0,e^{iπ/4}]] | π/4 相位 (π/8 门) |

## 决策：选哪个门 / 操作
- 要**等权叠加** → H（每比特一个）。
- 要**纠缠两比特** → CNOT（前置 H 制 Bell 态）。
- 要**翻转目标**（条件） → CNOT / Toffoli。
- 要**交换比特**且只有 CNOT → SWAP = 3×CNOT。
- 要**把经典函数塞进线路** → Toffoli + ancilla + uncompute。
- 要**编译任意 U(2)** → z-y-z 分解；离散集再用 Solovay-Kitaev。

## Bloch 球速记
- 纯态：球面，|r|=1；混合态：球内，|r|<1；最大混合 ρ=I/2 → 球心。
- |ψ⟩=cos(θ/2)|0⟩+e^{iφ}sin(θ/2)|1⟩；rᵢ=Tr(ρσᵢ)。
- 门 = 旋转：Rn(θ) 绕轴 n 转 θ。

## 测量概率速记
- 计算基测 α|0⟩+β|1⟩：P(0)=|α|², P(1)=|β|²。
- 测量后态塌缩到对应本征态；测量不对易（如 Z 后测 X 会"重置"Z 信息）。

## 复杂性 / 加速判断
| 现象 | 含义 |
|---|---|
| 经典获取信息量 > 答案所需信息量 | 有"计算冗余"→ 量子可能加速 |
| 问全局性质 (如 f(0)⊕f(1)) | 适合量子并行+干涉 |
| 因数分解 / 求阶 | QFT 家族，∈ BQP |
| 非结构化搜索 | Grover，O(N)→O(√N) |
| 模拟量子多体系统 | 量子模拟，指数→多项式 |
| BPP ⊊ BQP ? | 量子是否严格强于经典——核心开放问题 |

## 三条不可违反的红线
1. **不可克隆** → 禁止扇出/复制未知态。
2. **幺正可逆** → 禁止扇入、禁止环路。
3. **测量即塌缩** → 干涉做完再测，别中途窥探。
