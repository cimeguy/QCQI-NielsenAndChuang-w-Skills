# 术语表 · QCQI 第八章补充（量子信道）

**Bloch 仿射变换** — 单 qubit 信道写成 r→Mr+c (8.3)
**Choi-Jamiołkowski 同构** — 信道 ↔ 蔡氏矩阵一一对应 (8.1)
**CP（完全正定）** — ℰ⊗I 对任意扩展保持正定 (8.1)
**CPTP 映射** — 完全正定且保迹，量子信道的定义 (8.1)
**Kraus 算符 {E_k}** — ℰ(ρ)=ΣE_k ρ E_k†，ΣE_k†E_k=I (8.2)
**Kraus 秩** — 非零 Kraus 算符个数 = 蔡氏矩阵非零本征值数 (8.2)
**Perturbative QEC** — 扰动量子纠错，验证公式 (18)≡(20) (8.4)
**TP（保迹）** — Tr(ℰ(ρ))=Tr(ρ)，概率守恒 (8.1)
**transfer matrix / 展平** — 把信道向量化为矩阵的表示 (8.4)
**比特翻转信道** — E₀=√(1−p)I, E₁=√p X (8.1,8.3)
**去极化信道** — 以概率 p 替换为最大混合，M 各向同性收缩 (8.3)
**振幅阻尼** — 能量耗散 |1⟩→|0⟩，仿射含平移 c=(0,0,γ) (8.3)
**最大纠缠态 |Ω⟩** — Σ|ii⟩，定义蔡氏矩阵用 (8.1)
**相位阻尼** — 衰减相干项，与相位翻转效果一致 (8.3)
**相位翻转信道** — E₀=√(1−p)I, E₁=√p Z (8.3)
**蔡氏矩阵 (Choi matrix)** — J(ℰ)=(ℰ⊗I)|Ω⟩⟨Ω|；CP⟺J≥0 (8.1,8.2)
**谱分解** — J=Σλ_k|v_k⟩⟨v_k| → Kraus 算符 (8.2)
