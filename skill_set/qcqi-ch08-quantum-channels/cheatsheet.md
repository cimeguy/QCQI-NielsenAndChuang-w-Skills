# 速查表 · QCQI 第八章补充（量子信道）

## 三种等价描述
| 描述 | 形式 | 合法性条件 |
|---|---|---|
| 信道映射 ℰ | ρ → ℰ(ρ) | CPTP |
| Kraus | ℰ(ρ)=ΣE_kρE_k† | ΣE_k†E_k=I |
| 蔡氏矩阵 J | (ℰ⊗I)|Ω⟩⟨Ω| | J≥0 且部分迹=I |

## 转换路线
```
信道 ℰ ──(ℰ⊗I)|Ω⟩⟨Ω|──► 蔡氏矩阵 J ──谱分解──► Kraus {E_k}
ℰ ──M_ij=½Tr(σ_iℰ(σ_j))──► Bloch 仿射 r→Mr+c  (单 qubit)
```

## 典型单 qubit 信道：Kraus
| 信道 | Kraus |
|---|---|
| 比特翻转 | √(1−p)I, √p X |
| 相位翻转 | √(1−p)I, √p Z |
| 相位阻尼 | 同相位翻转（退相干） |
| 比特-相位翻转 | √(1−p)I, √p Y |
| 去极化 | √(1−3p/4)I, √(p/4){X,Y,Z} |
| 振幅阻尼 | [[1,0],[0,√(1−γ)]], [[0,√γ],[0,0]] |

## 典型信道：Bloch 仿射 r→Mr+c
| 信道 | M=diag(·) | c |
|---|---|---|
| 比特翻转 | (1, 1−2p, 1−2p) | 0 |
| 相位翻转/阻尼 | (1−2p, 1−2p, 1) | 0 |
| 去极化 | (1−p, 1−p, 1−p) | 0 |
| 振幅阻尼 | (√(1−γ), √(1−γ), 1−γ) | (0,0,γ) |

## 关键判据
- **CP** ⟺ 蔡氏矩阵 J ≥ 0。
- **TP** ⟺ ΣE_k†E_k=I（⟺ J 部分迹=I）。
- **Kraus 秩** = J 的非零本征值个数。
- **Kraus 非唯一**：差一个幺正混合 F_j=Σu_{jk}E_k。

## 记忆点
- 相位阻尼 ≡ 相位翻转（都只衰减相干项）。
- 去极化各向同性收缩；振幅阻尼收缩 + 向 |0⟩ 平移（唯一 c≠0）。
- Perturbative QEC：公式 (18) ≡ (20)，数值验证通过。
