# 8.2 从蔡氏矩阵到 Kraus 算符

## 核心思想
蔡氏矩阵 J(ℰ) 是半正定矩阵，对它做谱分解（求本征值与本征态），每个本征对就给出一个 Kraus 算符。这是从信道矩阵表示恢复算符和表示的标准途径。

## 谱分解 → Kraus
- 对 J(ℰ) 做谱分解：J = Σ_k λ_k |v_k⟩⟨v_k|，λ_k≥0（因 J 半正定）。
- 每个本征向量 |v_k⟩（d²维）按"向量化逆操作"reshape 成 d×d 矩阵，再乘 √λ_k，即得一个 **Kraus 算符** E_k = √λ_k · mat(|v_k⟩)。
- 于是 ℰ(ρ)=Σ_k E_k ρ E_k†，且保迹 Σ_k E_k†E_k=I。

## 讨论蔡氏矩阵的本征值与本征态
- **非零本征值个数** = 信道的 **Kraus 秩**（最少需要的 Kraus 算符数）。
- 本征值 λ_k 给出各 Kraus 通道的"权重"；λ_k=0 的方向不贡献 Kraus 算符。
- **Kraus 表示不唯一**：任意一组 Kraus {E_k} 与另一组 {F_j} 等价 ⟺ 差一个幺正混合 F_j=Σ_k u_{jk}E_k（谱分解给出的是正交规范的一组）。

## 关键要点
1. J 半正定 ⇒ 谱分解 J=Σλ_k|v_k⟩⟨v_k|，λ_k≥0。
2. 每个 (√λ_k, |v_k⟩) → 一个 Kraus 算符 E_k（向量 reshape 成矩阵）。
3. 非零本征值数 = Kraus 秩；Kraus 表示差一个幺正自由度，不唯一。
