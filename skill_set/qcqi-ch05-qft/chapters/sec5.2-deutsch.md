# 5.2 Deutsch 与 Deutsch-Jozsa 算法

## 核心思想
量子并行：量子计算机能在同一个幺正变换中同时计算 f(x) 在许多 x 处的值。Deutsch 算法是这一思想最简单的范例。

## Deutsch 算法
- **问题**：f:{0,1}→{0,1}，判断 f 是**常数型**（f(0)=f(1)）还是**平衡型**（f(0)≠f(1)）。
- **常数型例子**：f(x)=0 或 f(x)=1；**平衡型**：f(x)=x 或 f(x)=1−x。
- **关键**：每个量子线路只用一次 Uf，即一次计算就完成经典需要两次计算才能完成的任务（判断 f(0)⊕f(1)）。
- **机制**：辅助比特置 |−⟩，相位回踢使 |x⟩→(−1)^{f(x)}|x⟩；对查询比特做 H 干涉，末端测量直接读出 f(0)⊕f(1)。

## 启发
- 对那些**经典计算获得的信息量超过问题答案所需信息量**的问题（即经典存在计算冗余），量子计算具有潜在加速可能。
- 判断"全局性质"（如 f(0)⊕f(1)）特别适合量子并行 + 干涉。

## Deutsch-Jozsa 算法
- **推广**：f 有 n 个输入位，承诺 f 要么常数要么平衡，判断属于哪种。
- **经典**：最坏需 2^{n−1}+1 次查询确定；**量子**：一次 Uf 即可（确定性）。
- 对应 Nielsen Sec.1.4.4。

## 关键要点
1. 量子并行 = 一个幺正变换同时算多个 f(x)；但读出受测量限制。
2. Deutsch：一次 Uf 判常数/平衡，经典需两次。
3. 计算冗余 ⇒ 量子加速潜力；全局性质问题适合 QFT/干涉类算法。
